## 4. 固定偏差 vs 随机偏差判定

**随机偏差**：E_plan 方向在每次规划间随机翻转（X 分量 −8.5…+8.1，Y −9.3…+9.1，Z −9.9…+8.6），标准差 ~3–7mm，与 PositionConstraint ±1cm 盒内均匀落点模型吻合。
**无固定方向**：均值向量模 ~7mm 且方向不稳定（P2 与 P4 均值方向不同），不构成"固定 2–3cm 系统偏差"。
