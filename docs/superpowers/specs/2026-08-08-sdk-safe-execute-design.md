# SDK 执行安全闭环设计（2026-08-08）

## 背景与事故

2026-08-08 真机 SDK 候选扫描（`scripts/sdk_candidate_scan.py`）中，候选 [6]
（score=0.649）目标 J6=(524,98,151)mm rpy=(92,85,16)° 被固件"接受"后执行到
错误位形 (53,-10,190)mm——末端折回 base 原点附近，与底座碰撞，强制断电。

根因链：
1. **欧拉角奇异区**：目标 RY=85° 接近万向节锁定（β=±90°），`matrix_to_rpy`
   分解数值不稳定，固件对欧拉角输入的解释与 SDK 不一致 → 目标被误解。
2. **固件多解**：固件"接受"≠ 按目标执行；奇异附近输入可能走向错误逆解分支。
3. **SDK 链路无保护**：无碰撞检测（MoveIt 的碰撞检测在 FakeSystem 链上，
   SDK 直控链路裸奔）；回验在运动完成后才检查（484mm 偏差发现时碰撞已发生）。

## 目标

SDK（EndPoseCtrl）执行路径具备三层防护：
- 发送前：候选姿态奇异过滤 + 位置粗筛 + 连杆级碰撞预检（pinocchio）
- 执行中：FK 实时监控（100ms），禁区进入/位置突变 → 急停
- 执行后：FK 回验偏差检查 → FAIL 回 zero

## 禁区定义（用户确认参数）

| 禁区 | 几何 | 数值 |
|------|------|------|
| 底座包围盒 | AABB，中心 (0,0,60)mm，尺寸 **150×150×120mm**（长×宽×高，含余量；z∈[0,120]mm） | 连杆端点（link1~link7 各杆两端，base 系）与盒面距离 < 5mm（含盒内）→ 拒绝 |
| 底座平面下限 | 末端 J6 的 z 坐标 | z < 180mm → 拒绝（底座平面以上安全余量） |
| 底座圆柱 | 执行中监控：xy 半径 <250mm 且 z<400mm | 进入 → 急停（事故位形 xy=54mm 必触发） |

## 三层防护规格

### 第 0 层：候选过滤（发送前，纯计算）

1. **欧拉角奇异过滤**：目标 RY ∈ [-75°, 75°]，否则拒绝。
   （事故候选 [6] RY=85° 必须被此层拦截——回归用例）
2. **位置粗筛**：J6 目标 xy 半径 > 250mm 且 z > 180mm，否则拒绝。
   （粗筛提前拦截明显禁区目标，避免进第 1 层）

### 第 1 层：连杆级碰撞预检（pinocchio，不动真机）

1. **IK 求解**：J6 目标（位置+姿态）→ pinocchio DLS 数值 IK（复用
   `grasp_ik.py` 的 DLS 实现）→ 关节解；无解/不收敛 → 拒绝。
2. **关节限位**：解在 URDF joint limits 内，否则拒绝。
3. **连杆-底座碰撞**：pinocchio FK（解）→ 每连杆（link1..link7）两端点
   base 系坐标 → 任一端点与盒面距离 < 5mm（含盒内）→ 拒绝。
4. **末端 z 下限**：J6 z < 180mm → 拒绝。

任一失败 → 候选拒绝（不发送）。

### 第 2 层：执行中实时监控（独立线程，急停）

发送 EndPoseCtrl 后启动监控线程，每 100ms 采 `GetFK('feedback')` 位置：

| 触发条件 | 规则 | 备注 |
|----------|------|------|
| 禁区进入 | J6 位置 xy 半径 < 250mm 且 z < 400mm | 事故位形 xy=54mm 必触发 |
| z 平面穿透 | J6 z < 180mm | 底座平面保护 |
| 位置突变 | 单帧位移 > 30mm/100ms | 异常高速/跳变 |

急停序列（任一触发）：
1. `piper.MotionCtrl_1(0x01, 0, 0)`（快速急停）
2. `piper.MotionCtrl_1(0x00, 0x06, 0)`（终止执行）
3. 确认停止（FK 稳定）→ MoveJ 回 zero（5%）

### 第 3 层：执行后回验（保留现有）

FK 稳定判据（连续 4 次采样变化 <1mm）→ 对比目标：
- 位置偏差 > 50mm 或姿态偏差 > 10° → FAIL → MoveJ 回 zero

## 模块实现

**新模块**：`scripts/sdk_safe_execute.py`

```
sdk_safe_execute.py
├── ForbiddenZone 类：包围盒/圆柱/z 下限几何查询（含 5mm 缓冲）
├── filter_candidate()：第 0 层 + 第 1 层（奇异过滤 → 粗筛 → IK → 连杆检查）
├── MonitoredSend()：第 2 层（EndPoseCtrl + 监控线程 + 急停序列）
├── verify_and_recover()：第 3 层（稳定判据 → 回验 → 回 zero）
└── main()：候选循环（score 降序，逐个过滤→发送→回验）
```

常量参数（模块头部，便于现场调）：
- `BOX_CENTER = (0, 0, 0.06)`、`BOX_SIZE = (0.15, 0.15, 0.12)`
- `Z_MIN = 0.18`、`XY_CYL_R = 0.25`、`CYL_Z_MAX = 0.40`
- `RPY_SINGULAR_LIMIT = 75`（度）、`POS_TOL_MM = 50`、`RPY_TOL_DEG = 10`
- `MONITOR_PERIOD_S = 0.1`、`JUMP_TOL_MM = 30`

**集成（双轨计划，用户既定）**：`grasp_execute.launch.py` 加
`execute_backend: moveit|sdk` 参数（默认 moveit 保现有行为）；SDK 路径强制
安全闭环（本设计全部层）。MoveIt 路径不变。

## 测试计划

### 纯计算单测（不动真机）

1. **回归用例（事故候选 [6]）**：目标 rpy=(92,85,16)° → 第 0 层奇异过滤
   必须拒绝（RY=85° > 75°）
2. **奇异边界**：RY=75° 接受、75.1° 拒绝
3. **包围盒碰撞**：构造连杆端点进入盒内的关节解 → 拒绝；贴盒边（5mm 缓冲
   边界）→ 边界行为验证
4. **z 下限**：J6 z=179mm 拒绝、181mm 接受
5. **圆柱/突变规则**：监控触发条件纯函数测试

### 真机测试（断电恢复后）

1. 安全候选执行全流程（过滤 → 发送 → 监控 → 回验 → 回 zero）
2. 急停功能实测：监控线程手动触发一次（构造突变条件）→ 验证急停序列生效
3. 事故候选回归：真实事故候选 [6] 走完整流程 → 必须被第 0 层拒绝、臂不动

## 安全说明

- 全程 5% 速度（move_spd_rate_ctrl=5）
- 急停后必须人工确认再继续
- 执行前机械臂回 zero（MoveJ）作为基线
- 断电恢复后先验证使能/急停可用再跑扫描

## 遗留

- 连杆端点检查保守（端点不在盒内但连杆中部可能进入）——本次按用户裁决用端点；
  后续可升级连杆扫掠体（胶囊体/线段-AABB 距离）
- 监控采样率受 SDK FK 线程 CPU 开销限制（demo 提示 CPU 占用近翻倍）——100ms
  实测验证，必要时降 200ms
- 底座包围盒按用户给定 150×150×120；若现场底座安装有偏斜，需实测校准
